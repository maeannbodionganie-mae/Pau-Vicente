# Pau Vicente — Speaker Portfolio

A buildless, responsive personal speaker website. The published files are in `dist/`.

## Editing

Authoritative sources, which you edit:

- `src/index.html`: the homepage. `src/event.html` is the event page template and `src/404.html` is the not-found page.
- `src/content/events.json`: **the single source for events.** It feeds the homepage feature, each `/events/<slug>/` page, and the assistant's event answers.
- `dist/assets/style.css` (design tokens and section tones at the top), `main.js` (navigation), `story.js` (header state and chapter index), `motion.js` (stage depth, storybook pages, reveals), `inquiry.js`, `register.js`, and the `pau-*` assistant files are hand-maintained in place.
- `dist/api/inquiry.js` and `dist/api/pau.js` are Vercel functions.
- `asset-map.json` maps the 15 supplied original filenames to optimized browser assets.

Generated by `python3 scripts/render.py`, so do not edit these by hand: `dist/index.html`, `dist/events/*/index.html`, `dist/404.html`, and the `event`/`registration` facts in `dist/assets/pau-knowledge.json`.

The `index.html`, `style.css`, `main.js`, image, and font files at the repository root are older copies. They are not published (Vercel serves `dist/`) and are kept only for history.

### Updating the event

1. Edit `src/content/events.json`. Use `"To be announced"` for anything unconfirmed. Never invent a date, fee, venue, capacity, or certificate.
2. For a real session, set `"status": "confirmed"`, update `statusLabel`, fill in `date`, `time`, `timezone` (for example `Asia/Manila`), `format` and `venue`.
3. Registration has three modes. `"preview"` is a local-only demo form. `"live"` shows a button to `registration.url`, which must be `https://` and cannot be used on a sample event. `"closed"` shows that registration has ended.
4. Run `python3 scripts/render.py`, then the checks below.

Sample events get `noindex` and visible *Sample event / Registration preview* labels automatically.

## Editorial redesign

The `redesign/editorial-speaker` branch implements the “A Story Worth Sharing” redesign. It retains buildless HTML/CSS/JavaScript and the existing Vercel `dist/` root. Read `REDESIGN_NOTES.md` for the section compositions, asset treatment, and verification limits.

The hero now uses the `pau-hero-editorial-*` transparent WebP derivatives through the same asset map as the other photographs, with a transparent PNG fallback. The original hero JPEG and earlier derivatives remain available. Social sharing uses the original JPEG for a reliable opaque preview.

For local review after extracting the project, open `dist/index.html` in a browser. For an HTTP preview on your own computer, run `python3 -m http.server 8000 --directory dist` from the project root, then visit `http://localhost:8000`.

## Contact and inquiries

The contact section has a validated inquiry form. Topic cards preselect their topic. Each inquiry gets a reference ID, is recorded in a private Google Sheet, and is emailed to Pau. A prefilled email link remains as a fallback. See `INQUIRY_SETUP.md` for setup, failure handling, and the required end-to-end test. Until the two Vercel environment variables are configured, the form says it is not yet available and offers the email route. Submitting an inquiry never confirms availability or a booking.

## Pau assistant

The draggable lower-right illustrated avatar opens a portfolio guide. It uses only reviewed public facts and declines unrelated questions. A server-side Gemini routing integration is ready for configuration; without a key it is explicitly a deterministic portfolio guide. Graphify is not connected pending identification of the intended service. See `PAU_ASSISTANT.md` for setup, safeguards, asset provenance, and verification limits.

## Accessibility

Semantic landmarks, a skip link, descriptive alternative text, keyboard-visible focus, a mobile menu with an expanded state and Escape handling, and reduced-motion support are included. Content is visible without JavaScript, including all story chapters and speaking details.
